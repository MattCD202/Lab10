ЛАБОРАТОРНАЯ РАБОТА №10 — ВЕРСИЯ ДЛЯ СТУДЕНТА
Visual Studio 2026 / .NET 10

Тема: разработка тестовых модулей проекта для тестирования отдельных модулей
и оптимизация программы.

Индивидуальный модуль:
Удаление повторяющихся элементов массива с сохранением порядка первого появления.

Параметр оптимизации:
Время выполнения.

ЧТО УЖЕ ПОДГОТОВЛЕНО
1. Рабочее решение Visual Studio.
2. Консольная программа.
3. Исходный вариант алгоритма.
4. Отдельный метод, предназначенный для оптимизации.
5. Тестовый проект MSTest.
6. Два готовых примера тестов.
7. Программа для измерения времени до и после оптимизации.

ЧТО НУЖНО СДЕЛАТЬ СТУДЕНТУ
1. Открыть OptimizationLab10.sln.
2. Выполнить Сборка -> Пересобрать решение.
3. Открыть Тест -> Обозреватель тестов и убедиться, что готовые тесты выполняются.
4. Добавить не менее 4 собственных тестов для исходного модуля.
5. Запустить все тесты и исправить найденные ошибки.
6. Изучить RemoveDuplicatesOriginal и определить, почему алгоритм работает медленно на больших массивах.
7. Оптимизировать RemoveDuplicatesOptimized. Исходный метод не изменять.
8. Повторно запустить все тесты. После оптимизации поведение программы должно остаться правильным.
9. Запустить консольный проект и записать результаты 5 измерений.
10. Сравнить среднее время исходного и оптимизированного вариантов.
11. Рассчитать процент изменения времени выполнения.
12. Оформить отчет.

РЕКОМЕНДАЦИЯ ПО ОПТИМИЗАЦИИ
В проекте специально оставлен неэффективный двойной цикл. Подумайте,
какую структуру данных можно использовать для более быстрого определения,
встречался ли элемент раньше.

ТРЕБОВАНИЯ К ОТЧЕТУ
Согласно методическим указаниям:
- Times New Roman, 12;
- межстрочный интервал 1,5;
- отступ слева 1,5;
- выравнивание по ширине;
- скриншоты должны иметь подписи;
- названия разделов «Практическая работа», «Цель работы», «Ход работы»,
  «Вывод», «Ответы на контрольные вопросы» выделяются жирным.

РЕКОМЕНДУЕМЫЕ СКРИНШОТЫ
1. Исходный метод RemoveDuplicatesOriginal.
2. Тестовый класс с собственными тестами.
3. Обозреватель тестов с результатами.
4. Исходные измерения времени.
5. Измененный метод RemoveDuplicatesOptimized.
6. Повторные измерения времени.
7. Итоговое сравнение.

ВАЖНО
Фактическое время выполнения зависит от компьютера. Не вставляйте придуманные
значения — используйте результаты собственного запуска.
